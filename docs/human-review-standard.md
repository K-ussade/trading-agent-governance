# Human Review Standard

## Purpose

This standard defines human review gates for supervised trading-agent governance documentation.

## Review Gates

| Gate | Required Before | Reviewer Checks |
| --- | --- | --- |
| Scope review | Work begins. | Documentation-only scope, boundary class, and prohibited-content risk. |
| Risk review | Governance change is accepted. | Risk category, control, owner, and escalation path. |
| Change approval | Governance artifact changes. | Human approval, status label, and audit note. |
| Claim review | Public language is reused. | No financial advice, investment advice, performance claim, return claim, strategy, signal, or client outcome claim. |
| Publication review | Public push, release, profile link, or portfolio use. | Disclaimer, boundary, evidence, and prohibited-content exclusion. |
| Incident review | Work resumes after unsafe output or exposure. | Containment, correction, and follow-up control. |

## External Action Definition

External action includes publication, repository push, release, public issue comment, profile link, portfolio proof use, outreach, or any public claim about trading-agent governance.

## Approval Record

Each approval record should include:

- reviewer;
- artifact;
- date;
- decision;
- boundary classification;
- disclaimer status;
- prohibited material excluded;
- follow-up actions.

## Authority Rule

AI may draft governance documentation. AI does not approve financial claims, investment claims, compliance claims, legal claims, publication, or operational use.
