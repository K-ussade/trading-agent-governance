# Prohibited Content

## Purpose

This document defines material that must not be included in `trading-agent-governance`.

## Prohibited Trading And Financial Content

- trading bots;
- live autonomous agents;
- execution systems;
- broker integrations;
- order routing;
- trading strategies;
- signals;
- recommendations;
- portfolio allocations;
- buy, sell, hold, rebalance, or timing advice;
- returns;
- balances;
- positions;
- account screenshots;
- account data;
- performance claims;
- return claims;
- client outcome claims;
- claims that any system makes money.

## Prohibited Sensitive Content

- credentials;
- tokens;
- API keys;
- secrets;
- private prompts;
- private model outputs;
- private operations;
- private training corpora;
- customer data;
- donor data;
- student data;
- volunteer private data;
- private Foundation operations;
- exact sensitive infrastructure locations;
- security-sensitive NEURONA operational details;
- sealed YOSO-YAi LLC IP.

## Prohibited Advice And Authority Claims

- financial advice;
- investment advice;
- tax advice;
- legal advice;
- compliance certification;
- regulatory approval;
- production readiness;
- active service availability;
- client outcome claims.

## Handling Rule

If a requested change requires prohibited content, refuse the content and offer a public-safe governance placeholder instead.
