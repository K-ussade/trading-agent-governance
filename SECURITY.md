# Security Policy

## Reporting Sensitive Issues

Do not open a public issue containing credentials, tokens, API keys, secrets, account data, balances, account screenshots, broker details, private prompts, private model outputs, donor data, student data, volunteer private data, customer data, private Foundation operations, exact sensitive infrastructure locations, security-sensitive NEURONA operational details, or sealed YOSO-YAi LLC IP.

Use a private maintainer contact path until a formal security process is published.

## Public Issue Scope

Public issues may discuss:

- documentation clarity;
- broken links;
- template consistency;
- graph rendering;
- public boundary language;
- validation failures that do not expose sensitive material.

Public issues must not include:

- strategies, signals, returns, balances, account data, or performance claims;
- financial advice or investment advice;
- credentials, tokens, API keys, or secrets;
- private trading operations or private incident records;
- private prompts or model outputs;
- private training corpora;
- security-sensitive infrastructure details.

## Supported Scope

This repository is documentation-only. It does not run bots, connect to accounts, collect data, execute trades, route orders, host models, publish datasets, or operate demos.
